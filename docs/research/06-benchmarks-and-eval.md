## 2. 指标(必须同时报告,防止"全返回 unknown"刷低误报)

- **任务完成率**(独立外部验收器;见 §2.1)。
- **误报成功率 (false-success rate)**:系统报 pass 但**独立外部验收器**判 fail。← 头号指标。
- **非 pass 必须拆开报告**(否则无法衡量"拒判"的代价):
  - **证实失败 (confirmed fail)**:有证据表明**没达成**;
  - **证据不足 (insufficient evidence)**:`ambiguous/unobservable`(真正的"弃权");
  - **执行阻断 (blocked)**:策略/前置/权限/中断导致**没执行**。
  分别报 rate,**不要合并成"abstention"**;只有 `ambiguous` 才对应我们说的"拒判"。
- **误报率的分母说清**:分子 = `系统报 pass` 且 `独立验收判 fail`;
  分母 = **所有系统报 pass 的实例**(按任务/按尝试须写明)。
- **技能库污染率**:入库技能中,在留出种子上重放失败的比例(SkillGen/GCPC 式)。
- **修复/回归 (repair/regression)**:同一实例 with/without 技能的净效果(SkillGen 式)。
- **安全停止延迟**:危险出现 → 控制停止的 tick 数。
- **恢复成功率**:中断后重新核对并继续完成的比例。
- **代价**:LLM token、MCP/工具调用数、墙钟、资源消耗。
- **能力分级消融**:分别撤掉 (a) 服务端特权验证、(b) 视觉后备,报告规划可见/验证可见/动作权限。

### 2.1 独立外部验收器(防止误报率循环定义)

系统内部判定(`13` 的 Fabric 权威状态 + 谓词)与"真值验收"**必须相互独立**,
否则误报率会被压到 ~0(`13 §1.4` 与外部验收器若共享同一事实与谓词,就是在自证)。
验收器至少满足其一:
- **独立实现的任务判定脚本**(不由断言引擎生成、不共享谓词/事实来源);
- **隐藏状态 / 隐藏目标**:测试时对系统不可见,验收时读出;
- **不同来源/模态**(服务端存档离线判定、结构化日志离线重放);
- **人工抽检**(标注一小部分)。
并记录:验收器与系统**是否复用同一判定谓词/结论来源**。
**可以**读取同一世界状态(同一份真值),关键是**判定逻辑独立**(不同判定实现 / 不同目标读法 / 隐藏目标)。
只有"复用系统谓词、或直接采信系统结论"时,该差异才不可作为误报证据。

## 3. 推荐的首批可证伪实验(与 framework/layering 的"先局部闭环"路线一致)

**固定版本 + 可复位服务器**,选三种反馈性质不同的任务:
1. **采集并获得木材**(目标物 + 掉落物,两个独立证据);
2. **按小蓝图建一座可通行桥**(体素目标 + 通行语义,两步验证);
3. **探索到目标区域并安全返回**(高熵探索 + 终止后置 + 安全不变量)。

**每任务施加扰动**:跨地图种子、材料缺失、目标被外部实体改变、怪物接近、服务端拒绝、
观测中断、重复请求。

**消融链(核心;每项单独开关,不同时加)**:
① 开环动作链 → ② 只有终点检查 → ③ 逐步后置检查 →
④a +执行期安全不变量监视 → ④b +`ambiguous/unobservable` 细分 →
④c +因果归因 → ⑤a +局部修复 → ⑤b +技能入库。
**再各撤一项**:撤服务端特权验证;撤视觉后备。
> 目的:能把"局部修复"和"技能入库"的增益**分开**,也能单独看"细分"与"归因"各自值不值。

**对照**:在**匹配环境**下与 Voyager(及其步骤暂停/特权假设)比较——同种子、同 Mod 特权、同暂停策略。

## 4. 为什么这能证伪(而非自证)

- 若 ④→⑤ 的增益无法在"误报率↓且拒判率可控"上体现,则机制价值被证伪。
- 若撤掉服务端特权验证后性能不降,则"特权 oracle 是必要条件"被证伪。
- 若 ⑤ 的额外代价(token/墙钟)超过收益,则"可接受的额外成本"不成立。
