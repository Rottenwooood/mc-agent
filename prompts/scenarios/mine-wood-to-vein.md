# 场景：挖木头 → 木镐 → 石头 → 石镐 → 矿脉

用 `mc-agent` 工具，在一个**全新世界（空背包）**里完成下面这条链。**每一步都以服务端权威背包为准**。

1. **挖木头** — 得到原木（如 `spruce_log`）。
2. **合成木镐** — `wooden_pickaxe`。
3. **挖石头** — 得到圆石 `cobblestone`。
4. **合成石镐** — `stone_pickaxe`。
5. **挖一条矿脉** — 得到对应矿石（如煤 `coal`）。

要求：
- 挖完方块记得 `collect` 捡掉落物。
- 每一步用 `get_inventory` 验证，别只看动作返回。
- 结束时给出：每一步的 `pass/fail` + 背包证据（物品 id + 数量）。
